## Character / 角色

Hanhan is based on the user-supplied design references in `reference/`. Hyper3D Rodin generated the accepted base mesh. Local Blender work produced mesh refinement, props, rigging, expression controls and state animation. Public repository availability does not establish a project-wide reuse license.

憨憨依据 `reference/` 中用户提供的角色参考重建。Hyper3D Rodin 生成了确认的基础网格，后续网格修整、配件、绑定、表情控制与状态动画使用本地 Blender 制作。项目公开不代表已设置统一的再使用许可。

## Laughter / 笑声

- Original: **Tiny creatures sounds / laugh.ogg** by **fvcalderan**.
- Source: https://opengameart.org/content/tiny-creatures-sounds
- License: **CC0 1.0**, https://creativecommons.org/publicdomain/zero/1.0/
- Changes: filtering, loudness normalization, edge fades, mono 24kHz PCM.
- 原音频经过滤波、响度归一化、淡入淡出及单声道转换。
- Original retained in `reference/audio/`; preview copy and license text in `web/public/assets/`.
